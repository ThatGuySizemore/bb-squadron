# House rules

Keep your lasting preferences, Never rules, Held actions and dated rulings in this private file at `~/.bb-squadron/house-rules.md`. Both Claude and Codex read it across projects. Its Never and Held entries beat every other rule. Add a permanent ruling only when you ask for one, dated and in your words.

Repo rules belong in the repo's `AGENTS.md` and `docs/agents/`. Project settings belong in `docs/agents/squadron.md`. Devices, tools, identities and machine-specific project notes belong in This machine. Secrets stay in BB's secret settings or the owner's credential tools, never in these files.

## Preferences

Add the owner's lasting preferences here.

## Never

Add only the owner's explicit permanent prohibitions here.

## Held

Add actions that need the owner's explicit approval here.

## Standing rulings

Add dated, verbatim permanent rulings here. An approval for one action stays in its thread or issue. Stops are BB thread states; wind-down comments record progress only.
